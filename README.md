# Titanic Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project explores the Titanic passenger dataset to understand passenger information and identify patterns in the data.

Exploratory Data Analysis (EDA) is used to inspect, clean, summarize, and visualize the dataset.

## 🎯 Project Objectives

- Understand the Titanic dataset.
- Perform data cleaning and preprocessing.
- Explore passenger information.
- Identify relationships between different variables.
- Create meaningful visualizations.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab / Jupyter Notebook

## 🔍 Project Workflow

1. Load the Titanic dataset.
2. Understand rows, columns, and data types.
3. Identify missing values and duplicates.
4. Clean and preprocess the data.
5. Perform exploratory data analysis.
6. Create charts and visualizations.
7. Interpret the results.

## 📊 Analysis Areas

- Passenger age distribution.
- Passenger class distribution.
- Gender distribution.
- Survival distribution.
- Relationship between passenger characteristics and survival.
